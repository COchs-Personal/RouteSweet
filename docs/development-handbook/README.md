# RouteSweet Development Handbook

This handbook explains how this project works and how to continue developing it without an assistant. Read the project and architecture chapters before a structural change, follow the local setup for an isolated working copy, and use the development recipes and recovery chapter while implementing or diagnosing a change. It contains implementation details, practical usage, diagrams, known gaps, and exact source references for the inspected revision.
